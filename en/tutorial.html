Nginx Proxy Manager reverse proxy guide

Bring your home services online, safely

From the HAOS install, first login and your first Proxy Host, all the way through DNS, SSL, Cloudflare Tunnel, Access Lists, backup, hardening and full troubleshooting. 12 chapters, about 10 minutes each. The Sales Handbook, Prompt Library and Skill Handbook are in the Resource Hub.

Basics: orientation and install

01

Getting to know Nginx Proxy Manager

Understand reverse proxies, domains, DNS and HTTPS first, then confirm what problems NPM solves.

 02

Install Woow Nginx Proxy Manager

Add the WoowTech NPM add-on to Home Assistant and check ports 80, 81 and 443.

 03

First login and account security

Log in with the default credentials, then change the email and password immediately to protect the admin interface.

 04

The admin interface and the core objects

Get to know Proxy Hosts, Certificates, Access Lists, Streams and Users.

Build: publish your first service

05

Create your first Proxy Host

Point an external domain at Home Assistant, a NAS or another internal service.

 06

DNS and domain resolution

Create A/CNAME records, and understand public IPs, Cloudflare Proxy and DNS propagation time.

 07

Request and manage SSL certificates

Get a certificate with HTTP-01 or DNS-01, turn on Force SSL and confirm automatic renewal.

Advanced: security and routing

08

Cloudflare Tunnel with NPM

Publish through a Tunnel instead of opening router ports, and let NPM handle the internal reverse proxy.

 09

Access Lists and access restrictions

Protect the web services you proxy with Basic Auth, IP allowlists and denylists.

 10

Redirects, Streams and WebSocket

Handle 301/302, TCP/UDP forwarding, WebSocket and custom Nginx config.

Operations: maintenance and troubleshooting

11

Backup, updates and hardening

Back up SQLite, the certificates and the config, then plan updates, admin interface protection and least privilege.

 12

Common errors and full diagnosis

Locate the problem layer by layer, from DNS, ports, upstream and 502 through to SSL and Cloudflare.

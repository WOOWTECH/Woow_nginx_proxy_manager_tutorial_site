Nginx Proxy Manager 反向代理指南

把家中服務安全帶上網

從 HAOS 安裝、首次登入與 Proxy Host 開始，一路完成 DNS、SSL、Cloudflare Tunnel、Access Lists、備份、安全加固與完整排錯。12 章，每章約 10 分鐘。銷售手冊、提示詞庫與 Skill 手冊在 資源總覽。

基礎：認識與安裝

01

認識 Nginx Proxy Manager

先理解反向代理、網域、DNS 與 HTTPS，確認 NPM 能解決什麼問題。

 02

安裝 Woow Nginx Proxy Manager

將 WoowTech NPM add-on 加入 Home Assistant，檢查 80、81、443 連接埠。

 03

首次登入與帳號安全

使用預設帳密登入後立即更改 email 與密碼，保護管理介面。

 04

管理介面與核心物件

認識 Proxy Hosts、Certificates、Access Lists、Streams 與 Users。

建置：公開第一個服務

05

建立第一個 Proxy Host

把外部網域導向 Home Assistant、NAS 或其他內部服務。

 06

DNS 與網域解析

建立 A／CNAME 記錄，理解公開 IP、Cloudflare Proxy 與 DNS 生效時間。

 07

申請與管理 SSL 憑證

使用 HTTP-01 或 DNS-01 取得憑證，啟用 Force SSL 並確認自動續期。

進階：安全與路由

08

Cloudflare Tunnel 搭配 NPM

不開路由器 port，以 Tunnel 對外，NPM 負責內部反向代理。

 09

Access Lists 與存取限制

用 Basic Auth、IP 白名單與黑名單保護受代理的 Web 服務。

 10

重導向、Streams 與 WebSocket

處理 301/302、TCP/UDP 轉送、WebSocket 與自訂 Nginx 設定。

管理：維運與排錯

11

備份、更新與安全加固

備份 SQLite、憑證與設定，規劃更新、管理介面保護與最小權限。

 12

常見錯誤與完整排查

從 DNS、port、upstream、502、SSL 到 Cloudflare 逐層定位問題。
